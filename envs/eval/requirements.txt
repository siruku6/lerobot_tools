# 評価用 venv に入れるもの
#
# Usage
# ------
#   envs/eval/steps/venv.sh がこのファイルを pip install -r で読む
#
# Effect
# ------
# 採点環境と同じ顔ぶれの venv が出来る。
#
#
# 何を基準に並べているか
# ------
# 採点環境の setup.sh が入れているものを、そのまま保つことを基準にしている。
# 評価パイプラインが使わないものも残す。参加者の提出物が import する可能性が
# あり、採点側に在るものをこちらで落とすと、ローカルで通って本番で落ちる
# という向きの食い違いが生まれるためである。
#
# torch と numpy もここに書く。以前は versions.env に持たせていたが、
# 版は環境ごとに違う（train は numpy 2.2.6 / torch は cu128）ため、
# 共通の場所に置くと名前が増えて、どれがどこで使われるか分からなくなる。
#
# torch は PyPI の既定 wheel ではなく PyTorch の index から入れる。
# その指定は下の --extra-index-url が持つ。
#
# 印の意味:
#   [libero]  LIBERO-plus 本体が import する
#   [eval]    評価パイプラインが import する
#   [保険]    どちらも import しないが、採点環境に在るので残す

# PyTorch の index。採点環境と同じ CUDA 13 の wheel を使う。

                                   # 変わり、同じコードが違う値を返しうる
torch==2.11.0                      # 採点環境と同じ。上の index から cu130 が入る
