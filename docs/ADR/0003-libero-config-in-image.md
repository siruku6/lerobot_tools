# LIBERO の設定（config.yaml）を data image に焼き込む

## 背景

LIBERO は `LIBERO_CONFIG_PATH` 環境変数を見て、設定ファイルの場所を決める。
この環境変数が無ければ `~/.libero/config.yaml` にフォールバックする
（`libero/libero/__init__.py` の挙動）。

`$HOME` にファイルを書く方式だと、実行するユーザー・コンテナ・マウント先が変わるたびに
設定が壊れる、または存在しない状態になる。移行元のリポジトリ（PARC2026 コンペティション
向けの旧リポジトリ）では、これを `env.sh` が「無ければ作る」という処理で都度カバーしており、
二重に面倒を見る構造になっていた。

## 決定

LIBERO の設定ファイル（`config.yaml`）を、`$HOME` には書かず、**`libero-data` image の
中に焼き込む。** `LIBERO_CONFIG_PATH` 環境変数でその場所を指すことで、LIBERO に
`~/.libero/config.yaml` を見に行かせない。

## 影響

- **良い面**: 実行するユーザー・コンテナ・マウント先が変わっても、設定ファイルが
  存在しない／古い、という状態が起きない。`env.sh` のような「無ければ作る」処理も不要になる。
- **悪い面**: 設定ファイルは image に焼き込まれているため、実行時に書き換えることができない。
  設定を変える場合は data image を焼き直す必要がある。
